# Dominion

Voxelová sandbox survival hra s RPG prvky: rasy, atributy a dovednosti, nekonečný svět ve stylu Terralith, těžení, výroba a souboje. Hra běží na vlastním enginu v Rustu.

Tento repozitář slouží jen ke **stažení hry a jejím aktualizacím**. Zdrojový kód je soukromý.

## Stažení

Nejnovější verze je na stránce **[Releases](https://github.com/Jonaczech/Dominion-releases/releases/latest)**:

- `Dominion-Setup-<verze>.exe` – instalátor (doporučeno, nevyžaduje práva správce)
- `Dominion-<verze>-windows.zip` – přenosná verze, spusťte `DominionLauncher.exe`

Launcher sám hlídá nové verze a umí je nainstalovat.

Binárky nejsou podepsané, takže Windows SmartScreen může zobrazit varování. Pokračujte přes „Další informace → Přesto spustit“.

## Požadavky

Windows 10/11 (x64) a grafická karta s podporou DirectX 12 nebo Vulkan.
